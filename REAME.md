# C Programming - Array Programs

## About This Project

Hello! I am a beginner in C programming. This project contains four basic C programs based on 1D arrays, 2D arrays, and matrix operations.

I created this project to improve my programming skills and understand how arrays and loops work in C.

## Programs Included

### 1. Negative Elements in 1D Array

File Name: `1-Darray.c`

This program takes array elements from the user and displays all negative elements.

### 2. Largest Element in 2D Array

File Name: `2-Darray.c`

This program takes the rows, columns, and elements of a 2D array from the user and finds the largest element.

### 3. Transpose of a Matrix

File Name: `2Dt.c`

This program takes the elements of a 3×3 matrix and displays its transpose.

### 4. Sum of a Row and Column

File Name: `sum.c`

This program calculates and displays the sum of a selected row and a selected column of a 3×3 matrix.
